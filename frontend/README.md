# MediDocs AI frontend

Angular 20 app (standalone components, signals, custom design system, no UI framework). See the main
[README](../README.md) for setup. Useful commands:

```powershell
npm start         # dev server on http://localhost:4200, proxies /api to the backend
npm test          # Vitest + jsdom unit and component tests (no browser needed)
npm run build     # production build into dist/medidocs/browser
```
